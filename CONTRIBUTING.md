# Contributing

Thanks for contributing. To keep this agent useful, please:

1. Open an issue describing a reproducible problem or a concrete task the agent mishandles.
2. Keep changes focused. Show the expected behavior, relevant framework/client versions, a safe example and the reason for each change.
3. Keep Claude `.md` and Codex `.toml` policies aligned in intent; platform-specific configuration can differ.
4. Validate Markdown YAML frontmatter and TOML syntax; preserve stable filename, agent identity and installation paths.
5. Update `VERSION`, `CHANGELOG.md` and the versioned release snapshots for behavior changes.
6. Do not disclose credentials, client data or proprietary code in public issues or PRs.

By contributing, you agree that your contribution is licensed under this repository's MIT license.
