# Changelog

All notable changes to this agent are tracked here.

## [1.1.0] - 2026-11-10

- New rule for user-facing explanations: use clear, simple language, or the language the user requests. Use short sentences and familiar words, explain technical terms and acronyms on first use, and describe what changed and why so a non-programmer can follow. Keep exact file paths, names, evidence, risks, and technical detail for developers. Do not invent code locations or claim checks that did not run.
- README links this agent as an alternative frontend for MyDevFactory: https://github.com/dimitriskl/mydevfactory.

## [1.0.0] - 2026-11-04

- Initial public, platform-specific Claude Code + Codex distribution.
- MIT license and step-by-step project/personal installation instructions.
- Version declarations and immutable versioned release snapshots.
